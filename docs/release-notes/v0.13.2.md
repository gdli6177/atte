Atte 0.13.2 · macOS Apple Silicon

## 本版更新

- Orca 准入由固定产品版本名单改为应用身份、CLI 接口与真实运行时能力检测。接口保持兼容的官方新版本可直接使用，无需等待 Atte 更新版本名单。
- 使用本机官方 Orca 1.4.259 完成真实终端契约测试，覆盖创建、消息完整投递与去重、定位和关闭。
- 切换前继续核对运行时身份、应用与运行时版本一致性及必要能力；发现不兼容时保留旧后端和现场，并显示具体原因。
- 设置中的“推荐安装包”与已安装版本的准入分开显示。安装入口更新为经过大小、SHA-256 和应用签名校验的官方 1.4.259 包，不自动降级已有 Orca。
- 补充未来版本准入、缺失接口/参数、运行时能力不足及真实设置选择入口的回归检查。

## 兼容性

保持 0.13.1 的工作区数据格式、目标、消息与 CLI 协议。原生 Agent 会话恢复仍按既有支持范围执行。

## 安装

仅支持 Apple Silicon Mac（arm64）。下载 DMG 或 ZIP 后替换 Atte.app；安装后在设置中重新安装 Atte CLI，使命令指向当前应用。

当前仍使用 ad-hoc 签名，未进行 Apple Developer ID 签名与公证。安装来源与 SHA-256 校验方式见仓库的安装说明。
