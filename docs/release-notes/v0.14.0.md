Atte 0.14.0 · macOS Apple Silicon

## 本版定位

每次交互都回到「注意力中心」：先记下，交给管家，只在决定、验收、到期跟进和真实介入时打扰你。

## 主要更新

- 执行后端收敛到 Herdr。外部 iTerm2、Terminal、Ghostty 仍是默认现场，内嵌轻现场继续作为回退；不再包含 Orca 安装、更新或后端切换。
- 目标入口收敛为「注意力、全部事项、设置」。项目与暂存筛选放在「全部事项」；首页只展示四类注意力，未到期的外部等待收为概览。
- 新事项不再提供“我来做”创建入口；`capture` 只暂存，保留对已有事项的人工接管。
- Agent 配置收敛为管家与负责人两项。负责人留空时继承管家。
- 设置页同步收拢：运行时维护、CLI / Skill 安装、缓存、诊断和 Webhook 默认折叠到“高级与维护”；项目授权显示默认外部审批和例外数量，按需展开配置。Hook 异常直接可见，准备管家和打开现场统一使用主入口。
- 移除本地能力包安装、脚本授权、Bot 协议、自主续跑、独立复核和自动验收。真实交付检查、人工验收、上线策略、高风险审批、决定账本、审查上限、提醒、巡检和回执恢复继续保留。
- 工作区快照升级到 v5。升级前校验备份；失败时停止且不覆盖原快照。旧的目标、消息、活动、附件、决定与交付记录保留。旧交付进入人工验收，未完成的实验任务暂停等待你确认。
- 旧 Orca 目标保留原始状态并标记为只读历史，不派发、不巡检、不恢复，也不关闭 Orca 或迁移终端。
- 修复受管 OMP extension 在子进程提前退出时因未处理 stdin `EPIPE` 杀死 OMP 会话的问题。Hook 输入有界排空、2 秒截止，失败仅记录脱敏分类并保持 Agent 回合不受影响。
- 已安装的 OMP extension 自动升级到 revision 3；旧的托管 `crewvane.js` 会安全收敛，用户同名文件、符号链接与其他扩展保持不变。
- 修复回执提醒投递：在可信 `turn.settled` 后等待约 10 秒再发送一次单行提醒；
  正文只通过 Herdr 官方 `agent prompt` 投递一次，保持 bracketed paste 和完整
  `ATTE_RECEIPT` marker；成功观察 `working` 即记为 `started`。只有 Codex 报
  `agent_prompt_stalled` 时，才在核实同一现场仍 `idle` 后读取最后一个 `›` 输入框；
  仅当该草稿仍含提醒正文时，补按 `agent send-keys <pane> enter`，最多 6 次，
  每次轮询 `working` / `blocked`，确认接手即停止补按。身份不符、现场不可达、
  不再 `idle` 或草稿消失也立即停止；不把 transcript 历史区当草稿，绝不重发正文。
  不能确认处理则记 `accepted`，由 `main` 向 Broker 返回 `unconfirmed`，不能算作
  `sent`，按回执检查流程交给管家核对。提醒后 30 秒仍无语义写回才标记
  `protocol_missing`；初始 `remindAt = settledAt + 10s`、`inspectAt = settledAt + 40s`，
  提醒流程结束后把 `inspectAt` 更新为 `remindedAt + 30s`。写回早于投递确认时保留
  `written`，并幂等补记一次提醒，不覆盖真实写回或重复记账。
- 修复看门狗单次记账：回执提醒成功交给管家时，`contactedAt` 只由协调收件箱的派发路径记录一次，Broker 不再重复写 `watchdog.report`。
- 已退役命令在 core、CLI 与桌面 IPC 入口统一于工作区读写前返回 `feature_removed`；桌面不再暴露“重新打开”等旧入口，避免从旁路重新启用退役能力。
- `atte hook ingest` 即使遇到缺失参数值或重复参数也保持 fail-open，退出码恒为 0；错误只进入脱敏诊断，不会反向影响 Agent。
- 修复 900px 窗口出现纵向滚动条时产生 11px 横向滚动的问题，注意力首页、全部事项与设置在最小窗口下保持单轴滚动。

## 升级注意

升级前关闭旧的 Atte 受管会话。工作区首次打开会创建并校验 `state.v4.backup.json` 后再迁移到 v5；如果备份或迁移失败，请保留原 `.atte` 目录并停止使用旧版本打开。回滚使用升级前备份，不要用旧版直接打开 v5 快照。

已经运行的 OMP 进程可能继续持有旧 extension 代码；升级后请重启相应 OMP 会话。如果旧 OMP 扩展曾崩溃，重启后可用 `atte doctor --json` 查看脱敏的 Hook 异常分类。

## 兼容性

保留 v2、v3 的既有迁移路径。已退役命令在读取或写入工作区前返回 `feature_removed`（退出码 2），历史记录仍可读取。`atte hook ingest` 的失败保持 fail-open，退出码为 0。

## 安装

仅支持 Apple Silicon Mac（arm64）。安装 DMG 或 ZIP 后启动应用即可；CLI 会随应用重新安装。
