Atte 0.13.3 · macOS Apple Silicon

## 本版更新

- 设置新增“排查与反馈”，可一键复制脱敏诊断报告；顶部菜单「Atte → 复制诊断日志」在界面异常时同样可用。
- 报告包含 Atte 与 Electron 版本、系统版本、工作区与会话后端状态、Herdr/Orca/CLI/Skills/Agent 接入概览，以及最近的错误事件。
- 报告不包含目标正文、消息、附件、终端输出、Webhook 地址或凭据；密钥、令牌、邮箱与带凭据的链接在写入前即被替换，绝对路径压缩为 `~` 或末尾两段。
- 事件持久化到应用数据目录的 `diagnostics.log`（权限 0600，单个文件上限 512 KB，保留一个轮转分代），重启后仍可复制上一次失败的记录。
- 界面脚本错误、主进程未处理异常、IPC 调用失败和渲染进程崩溃都会进入同一份报告，便于在其他机器复现问题时直接粘贴给维护者。

## 兼容性

保持 0.13.2 的工作区数据格式与协议；新增的日志只写入应用数据目录，不改变目标、消息或现场。

## 安装

仅支持 Apple Silicon Mac（arm64）。替换 Atte.app 后无需重装 CLI；如需更新 CLI 帮助文本，可在设置中重新安装 Atte CLI。
