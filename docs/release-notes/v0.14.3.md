# Atte 0.14.3

这次更新把 Atte 收紧为注意力中心，并修复现场恢复、OMP Hook、看门狗和升级链路中的高风险问题。

## 注意力与验收

- 待验收任务可以直接“补充要求，退回继续”，同时更新整体范围标题；原始需求保持不变。
- “给管家发消息”只处理普通提问，不再把补充要求误当成新的验收结论。
- 同一交付补充检查或证据使用 `goal.review --amend`，不重复占用审查轮次。
- 标题更新使用独立元数据活动，不再制造虚假的实质进展。

## 现场与可靠性

- Herdr 仍是唯一执行后端；运行时 generation 改变时，只有 Pane、launcher、进程组和前台 Agent 的连续稳定身份证据才能安全重绑。
- 没有稳定归属证据的旧现场必须由人确认；确认只退休旧 attempt，不关闭、不杀死旧 Pane。
- 目标完成不会静默关闭 legacy 现场；未核实的现场会保留在历史中等待人工确认。
- 看门狗保留 30 分钟后台核对、5 分钟失败重试和连续三次失败才打扰人的策略；未来时间戳不会再永久压制 stale。
- OMP extension revision 4 为子进程和 stdin 增加错误处理，避免提前退出触发 `EPIPE` 杀死会话；CLI ingest 继续完整排空大输入并保持 fail-open。

## 更新与设置

- 设置页精简为工作区、Agent、执行现场和应用更新；维护项收进“高级与维护”。
- 后台自动检查更新并下载，下载完成后只提醒一次；安装和重启必须由人点击。
- 退出安装前会协调在途工作、刷新收件箱并停止本地桥，不关闭 Herdr 或 Agent。
- 正式包使用固定自签名证书和 `dev.atte.desktop`，未使用付费 Apple Developer ID，也未经过 Apple 公证。
- 0.14.2 没有更新器，因此第一次升级到 0.14.3 仍需手动安装；从 0.14.3 起可在设置中接收后续版本。

## 安装

仅提供 macOS Apple Silicon（arm64）的 DMG、ZIP、`latest-mac.yml` 和 `SHA256SUMS.txt`。
首次打开如提示“无法验证开发者”，请核对发布来源与 SHA-256，然后在“系统设置 > 隐私与安全性”选择“仍要打开”。
