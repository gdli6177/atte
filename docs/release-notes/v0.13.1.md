Atte 0.13.1 · macOS Apple Silicon

## 本版更新

- 修复首次启动尚未选择存储位置时，左侧菜单只改变选中态、正文无法切换的问题。待办池与全部目标显示各自的引导，设置可以直接打开并首次选择存储位置；取消选择保留当前页面。
- 修复 Orca 已安装却显示“先安装”的错误提示。执行现场现在区分未安装、已安装但版本待验证、安装需修复和可切换，并说明真实原因；重新检测后安装卡片与执行现场状态同步更新。
- 移除侧栏重复的“我的工作台”区块，统一通过“注意力”返回总览。
- 品牌副标题统一为 `The attention layer`，去掉界面、关于面板、CLI 帮助与仓库首页中的中文品牌副标题。
- 吉祥物换成用户选定的装甲小管家：明显双耳、机甲护甲、墨黑与暖白配色、琥珀核心。首启、首页和管家卡片统一使用定稿透明原图并平滑缩放。

## 兼容性

- 工作区数据格式、目标、会话后端、Hook 与 Skill 接口继续与 0.13.0 兼容。
- Orca 的安装检测与版本兼容验收分别显示。本版已验证的官方安装版本仍为 1.4.258；其他版本会显示实际安装信息和验证状态，不自动放行，也不会自动降级已有应用。

## 安装

仅支持 Apple Silicon Mac（arm64）。从 Assets 下载 `.dmg`，将 Atte.app 拖入 Applications；也可下载 `.zip` 解压安装。

`SHA256SUMS.txt` 可用于校验下载文件。GitHub 自动生成的 Source code 是源码，不是安装包。
安装或替换应用后，在设置中重新安装 Atte CLI，确保命令指向当前应用。

当前安装包没有 Apple Developer ID 签名与公证，macOS 可能提示无法验证开发者。核对发布来源和 SHA-256 后，可在“系统设置 > 隐私与安全性”按提示选择“仍要打开”。
