# 设置布局与保存约定

本轮只重排现有功能，不合并、不删除功能。页面只有“功能分组 → 设置项”两层，
分组导航直接跳转到对应标题，不再给安装、Agent、工作区、策略混排编号。

| 分组 | 设置项与当前值 |
| --- | --- |
| 工作区与外观 | 工作区路径与更换、当前主题与保存、存储占用与清理 |
| 执行现场 | 当前会话后端与交接、打开方式与终端、Herdr 版本和状态、Orca 安装与更新 |
| Agent 与工作方法 | 管家 / 负责人 / 复核命令、Agent 生命周期接入状态、工作方法、CLI 安装路径、外部 Agent Skill 安装状态 |
| 授权与自主推进 | 项目上线策略、决定账本数量、实验功能与工作区 / 项目验收授权 |
| 通知 | 系统通知说明、Webhook 是否配置与启用、状态订阅和最近送达结果 |

“关于 Atte”保留版本、「注意力中心 · The attention layer」定位和功能解释，
名字由来不自动公开。
实验功能保持原默认与折叠行为，不因为重排而扩大任何执行授权。

## 显式保存

编辑字段后点击对应“保存”按钮才生效，包括主题、工作现场、Agent 命令、
上线策略、自主设置与 Webhook。工作现场在加载成功前不可保存；
有未保存更改时先保存再测试打开，避免测试旧值。保存失败显示错误并保留草稿；
保存成功更新当前值并提供反馈。外观页面的主题候选不提前写入持久键。

安装、更新、检测、停用、更换工作区、清理与后端交接是明确的命令操作，
点击对应动作后执行并展示结果。后端交接和脚本授权继续保留原确认与权限边界。
分组导航使用键盘可达的页内链接，窄窗口折成多行，卡片改为单列。
