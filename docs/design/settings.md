# 设置布局与保存约定

当前版本：Atte 0.14.1。设置采用渐进展示，沿用现有卡片、主题 token、
`details` / `summary` 和显式保存交互。产品说明见[使用说明](../atte.md)。

## 主层

| 分组 | 默认可见内容 |
| --- | --- |
| 工作区与外观 | 工作区路径与更换、主题选择与保存 |
| Agent | 管家 / 负责人启动命令、Agent 生命周期接入状态与处理入口 |
| 执行现场 | 默认打开方式、优先终端、当前生效值、保存与测试 |
| 通知 | 系统通知说明，以及 Webhook 在高级维护中的位置 |
| 上线策略与决定 | 外部审批默认说明、项目例外数量与配置入口、折叠的决定账本 |

Agent Hook 的等待信任、版本不支持、配置冲突和接入失败始终在主层显示文字
提示与对应处理按钮；不随高级维护一起隐藏。事件类型和最近事件时间可展开
“接入详情”查看。Hook 只观测生命周期，不代替 Atte CLI 的结构化写回。

设置不再提供“准备管家”和重复的“打开内嵌轻现场”动作。准备与返回管家使用
主导航的“找管家”；管家入口和事项中的现场入口按已保存的打开方式
进入同一 Herdr Session。需要内嵌方式时先选择并保存，再从主入口打开。

## 项目授权

默认策略为 `external-approval`，在主层只读说明，不新增工作区级策略写入。
已有项目的策略与审批人原样保留；统计非默认策略或已配置审批人的项目数量，
不因界面收拢而重置、迁移或扩大授权。

“配置项目例外”默认折叠，展开后才列出全部项目及其实际策略和审批人。
选择项目“配置”，编辑后点击“保存策略”才写入；取消、展开或折叠均不写入。
保存失败保留当前表单，明确取消或折叠项目列表放弃未保存草稿。高风险动作在
任何策略下仍需人确认。决定账本是独立的默认折叠区，不随项目配置自动展开。

## 高级与维护

“高级与维护”默认折叠，包含：

- Herdr 版本、可执行路径、插件状态、检查与安装更新、外部终端 attach 命令复制；
- Atte CLI 安装路径与重新安装；
- 外部 Agent 的内置 Atte Skill 状态、安装与更新；
- 缓存占用、重新扫描与缓存清理；
- 脱敏诊断日志复制；
- Webhook 的配置、状态订阅、送达结果与测试入口；
- 关于 Atte 与版本说明。

原生 `summary` 支持 Tab 聚焦、Enter / Space 展开与收起，使用全局焦点样式。
分组导航保留页内链接，定位高级维护时展开并聚焦其 summary；其他链接聚焦分组。
窄窗口中导航换行，卡片使用现有单列布局。折叠区不会改变已保存配置。

## 显式保存与验证

主题、工作现场、Agent 命令、项目策略和 Webhook 仍分别显式保存。
工作现场加载成功后才可保存；有未保存修改时禁用测试打开，避免测试旧值。
保存失败显示错误并保留草稿；保存成功更新生效值并反馈。主题候选不提前持久化。

安装、更新、检测、更换工作区与清理仍是点击后执行的明确命令操作。
不新增设计系统，也不改变安装、Hook 信任或授权语义。

冒烟脚本应先展开“高级与维护”再操作安装、缓存、诊断或 Webhook；项目策略
先展开“配置项目例外”。管家准备和内嵌现场测试改由主入口完成。测试仅使用
临时 fixture，不读取真实用户的工作区。
