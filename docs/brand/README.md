# Atte 品牌

Atte 的品牌标识与角色资产分工固定如下：

- **标识 = Six Vectors / 六向**：六条执行臂围绕同一个注意力核心。用于应用图标、
  Dock、菜单栏、favicon、侧栏、关于页、README 和字标。
- **吉祥物 = 角色插画**：原像素角色只用于首页、首启和管家卡片等应用内叙事，
  不是 Logo，也不进入应用图标或菜单栏。

标识的几何、最小尺寸、颜色、字标和禁用用法见
[Six Vectors 品牌使用规范](six-vectors.md)。颜色仅使用墨 `#171A1E`、暖白
`#F3F1EA`、琥珀 `#F5A524` 和图标底 `#14181B`。

命名与对外文案见[定位说明](positioning.md)；内部名字由来见
[命名记录](naming-origin.md)。运行时资产和生成流程见
[品牌资产清单](../../apps/desktop/assets/brand/README.md)。
