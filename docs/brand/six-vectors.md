## 1. 标识与文件选择

六个执行方向围绕同一个注意力入口。保留六向装甲结构，统一臂宽和端头几何；琥珀核心是唯一强调。

| 文件 | 用途 |
| --- | --- |
| `mark.svg` | 主标识。1024 × 1024 透明画布，显示尺寸 ≥33px |
| `mark-mono.svg` | 单色主标识。中心为真正透明的方形镂空，≥33px |
| `mark-small.svg` | 16–32px 光学版，透明底，平端粗臂 |
| `mark-reversed.svg` / `mark-mono-reversed.svg` / `mark-small-reversed.svg` | 深底反白版本，同一套几何 |
| `app-icon.svg` / `app-icon-1024.png` | 深墨圆角应用图标，标志为暖白色，琥珀核心 |
| `wordmark.svg` | 横向锁定：左标志、右 `atte`，已转路径 |
| `wordmark-stacked.svg` | 竖向锁定：上标志、下 `atte`，已转路径 |
| `wordmark-reversed.svg` / `wordmark-stacked-reversed.svg` | 两种锁定的深底版 |
| `preview.html` | 全部图形、像素样本、下载资源均内嵌，可离线单独打开 |
| `previews/` | 深浅底、实际像素样本、Dock 模拟、验证图与测量记录 |
| `sources/` | 几何参数、已提取的字体轮廓、预览与规范模板、重建脚本 |

PNG 小尺寸文件为真实 16 × 16 / 32 × 32 像素透明图。大幅预览的底色属于展示背景，不是 SVG 的一部分。

## 2. 几何规范

主标识使用 1024 × 1024 设计坐标，旋转中心固定为 `(512, 512)`。

| 参数 | 主标识 | 光学版 |
| --- | --- | --- |
| 六臂间隔 | 60°，0 / 60 / 120 / 180 / 240 / 300° | 相同 |
| 臂身宽 | 160 | 176，较主版加粗 10% |
| 外端径向距离 | 368 | 416，补偿小尺寸视觉收缩 |
| 最大端头宽 | 208 | 176，取消外扩端头 |
| 最外端斜切 | 每侧 40 × 40，局部 45° | 移除，改为平端 |
| 肩部斜切 | 每侧 24 × 24，局部 45° | 移除 |
| 轮毂外接圆半径 | 160，正六边形 | 取消独立轮毂 |
| 核心方块 | 128 × 128 | 128 × 128 |

主版的外端与肩部切角长度不同，角度均为相对臂轴的 **45°**；不含 22.5° 切角或任意斜率的渐缩边。局部轮廓使用 45° / 90°，整体仅按 60° 旋转。六边形边线沿 30° / 90° / 150°。

每份 SVG 只定义一条臂，六个 `<use>` 引用同一条路径。几何参数位于 `sources/build-assets.mjs` 的 `geometry` 对象；改单处后重建，所有方向和输出同步更新。

光学版加粗的是臂身；同时取消主版 208 宽的外扩端头，六个外侧缺口因此更开阔。不能用简单放大主版来替代光学版。

## 3. 光学居中与负空间

六臂及轮毂为严格的六次旋转结构，六个楔形负空间互为 60° 旋转副本，没有手工偏移某一条臂。核心方块也以 `(512, 512)` 为中心。

居中检查包括几何对称、1024px 透明像素面积质心、深浅底明度差加权质心和目视检查，没有只按外接矩形对齐：

| 检查对象 | 实测质心，像素边界坐标系 |
| --- | --- |
| 主标识 1024px | `(512.0083, 511.99754)` |
| 单色版 1024px | `(512.00877, 511.9974)` |
| 光学版 1024px | `(512.00749, 511.99904)` |
| 主版浅底，明度差加权 | `(512.00857, 511.99761)` |
| 主版深底，明度差加权 | `(512.00837, 511.99747)` |

核心的色彩重量集中在同一中心；更换深浅底没有产生单侧偏重。深浅底及 128px 检查后保留零位移，未额外向上或向旁边推移图形。六条臂在矢量上等宽，斜臂在低分辨率的灰度边缘与竖臂不同属于像素覆盖差异。

明度差加权采用线性 sRGB 相对亮度，与背景亮度的差值作权重；它是对视觉重量的辅助检查，结合目视结果判断，不将数值直接等同于所有人的主观感受。

## 4. 核心与单色

原稿的 96 × 96 核心调整为 128 × 128，线性增大约 33%，占画布宽度 12.5%。实际显示 32px 时为 4 × 4px，16px 光学版时为 2 × 2px。

`mark-mono.svg` 的核心使用 `fill-rule="evenodd"` 在轮毂上开孔。六臂不穿过这个方孔；不使用背景色盖住核心。因此放在任何单一底色上，方孔都会透出实际背景，去掉琥珀后结构仍完整。

单色印刷、蚀刻、压印使用 `mark-mono.svg`；深底使用对应的 `-reversed.svg`。不要直接隐藏彩色版的琥珀矩形，那会留下实心轮毂。

## 5. 颜色

| 名称 | HEX | RGB | 用法 |
| --- | --- | --- | --- |
| 墨色 | `#171A1E` | 23, 26, 30 | 浅底主形与字标 |
| 暖白 | `#F3F1EA` | 243, 241, 234 | 深底主形与字标；浅色展示底 |
| 琥珀 | `#F5A524` | 245, 165, 36 | 仅核心方块 |
| 应用容器底 | `#14181B` | 20, 24, 27 | 仅应用图标底板 |

每枚彩色标识的前景只有“墨色或暖白 + 琥珀”两色；单色版只有一个前景色。应用容器底按本次要求独立指定，不是增加第三种前景色。

统一使用实色、100% 不透明度。无渐变、投影、描边、光晕或材质效果。PNG 边缘因抗锯齿与背景混合产生的中间像素不作为新增品牌色。

## 6. 最小尺寸与安全边距

| 场景 | 最小尺寸 / 建议 |
| --- | --- |
| 单独彩色图形，16–32px | 必须使用 `mark-small.svg`，最小 16px |
| 单独主标识 / 主单色版 | 最小 33px；32px 及以下切换光学彩色版 |
| 应用图标 | 本包验证 128px Dock；若需要 ≤32px 的容器图标，应换用光学版重新导出 |
| 横向锁定 | 整张 SVG 最小显示宽 240px |
| 竖向锁定 | 整张 SVG 最小显示宽 160px |
| 印刷建议 | 单独主形高度 ≥10mm；横向锁定宽 ≥40mm；输出前看实际打样 |

上述单独图形尺寸指完整正方形 SVG 画布，不是裁到轮廓的尺寸。横、竖锁定尺寸同样包含文件自带的边距。

令主标识可见高度为 **H**；1024 坐标中 H = 736。通用安全边距 **X = 核心边长 = 128 = 4H/23 ≈ 0.174H**。从可见轮廓量起，文字、边框及其他品牌图形均不得进入 X 范围。

主标识 1024 画布本身已容纳 X；横、竖锁定额外内置 0.25H 外边距。光学版为紧凑图槽特例，自带外端 96 单位留白，即 16px 时 1.5px、32px 时 3px；不要再裁切。用在 UI 中时，与相邻内容另留至少 4px。Favicon 使用完整的 16/32px PNG 或光学 SVG。

应用图标底板为 1024 圆角方形，圆角半径 224，主标识可见高度占底板的 71.875%；128px 导出时圆角为 28px，主形高度为 92px。

## 7. 字标与固定锁定比例

字标为 **Futura Bold / `Futura-Bold`**，内容严格为全小写 `atte`。采用本机现有字体的原始字形轮廓，不描摹、不重造字母、不横向压缩、不修改字形。字距为 **−0.0125em**，即 1000 字号坐标下每对字母收紧 12.5。

交付 SVG 已转为路径，浏览、渲染及嵌入 README 均不需要安装该字体。`sources/wordmark-outline.json` 记录字形来源、原始字号、字距、边界与提取后的路径；不附带字体文件。

比例均以标志**可见高度 H**为基准：

| 关系 | 横向锁定 | 竖向锁定 |
| --- | --- | --- |
| 标志可见高 | 1H | 1H |
| 字标可见高 | 0.60H | 0.40H |
| 图文可见轮廓间距 | 0.25H | 0.25H |
| 四周内置留白 | 0.25H | 0.25H |
| 字标可见宽 | 1.726H | 横版的 2/3 |
| 图文合计可见宽 | 2.929H | 由字标宽决定 |
| SVG 画布 | 1371.63009 × 600 | 660.29155 × 860 |

横向字标的墨面积质心与标志核心水平线对齐，避免小写圆腹偏下造成“字沉下去”。竖向按可见字面水平居中。字重不再额外加描边，固定字标比例让标志保持主导。

使用时整体缩放锁定文件。不要分别调整图形与文字大小或间距，不要替换为系统默认字体。

README 示例：

```html
<picture>
  <source media="(prefers-color-scheme: dark)" srcset="atte-logo/final/wordmark-reversed.svg">
  <img src="atte-logo/final/wordmark.svg" width="320" alt="atte">
</picture>
```

以上相对路径按 README 所在目录调整。`<img>` 不会继承外部 CSS 颜色，切换主题时替换对应的 `-reversed.svg`；内联 SVG 可覆盖根节点的 `color`，保持琥珀不变。

## 8. 允许与禁止

**允许**

- 整体等比缩放，使用对应尺寸版本与深浅底版本。
- 在干净的实色背景上使用完整彩色版或单色镂空版。
- 保留安全边距，以固定横、竖锁定用于官网、README、签名与文档。
- 单色制造工艺使用中心镂空结构。

**禁止**

- 拉伸、倾斜、转动整枚标识，或将六臂改为非 60° 间隔。
- 单独移动、加粗某一臂，改变六个缺口的节奏。
- 把 16/32px 光学版用于大尺寸品牌主视觉。
- 将主标识直接缩到 16px，或把 16px PNG 插值放大作生产素材。
- 删除核心、将核心改圆、换成其他强调色，或用底色伪造单色孔洞。
- 添加渐变、投影、描边、发光、立体高光、透明度或复杂背景纹理。
- 重排字距、改大小写、添加自造字母或重新拼字。

## 9. 小尺寸验证

本轮使用环境已有 **Sharp 0.34.5 / librsvg**，未安装依赖。16px / 32px 分别按目标尺寸原生光栅化，没有先出大图再多次缩放，没有锐化或人工补像素。

检查材料：

- `previews/small-16.png` / `small-32.png`：浅底用实际透明图。
- `previews/small-16-reversed.png` / `small-32-reversed.png`：深底用实际透明图。
- `previews/small-16-8x.png`：真实 16px PNG 以最近邻放大 8 倍，透明底。
- `previews/size-validation.png`：原稿、主版与光学版的浅/深底并排验证；16px 放大 8 倍，32px 放大 4 倍。
- `previews/validation.json`：测量条件、几何参数、质心及像素统计。
- `previews/minimum-lockups.png`：横向 240px 与竖向 160px 的实际最小尺寸锁定。

| 检查项 | 16px 光学版 | 32px 光学版 |
| --- | --- | --- |
| 臂身理论宽度 | 2.75px | 5.5px |
| 平端离画布边缘 | 1.5px | 3px |
| 核心方点 | 2 × 2px，4 个完全不透明的原色像素 | 4 × 4px，16 个完全不透明的原色像素 |
| 透明面积质心 | `(7.99996, 7.99942)`，目标 `(8, 8)` | `(16.00586, 15.99947)`，目标 `(16, 16)` |
| 外圈方向分离 | 6 个独立像素连通区域 | 6 个独立像素连通区域 |

方向分离的统计方法：保留 alpha ≥160/255、像素中心位于半径 N/4 之外的像素，按上下左右四连通计数；该统计辅助检查方向是否粘连，不能替代目视判断。

**目视结论**：在原尺寸和 8 倍最近邻图上，16px 仍保留上下两臂及四个斜向分支，六个方向可逐一指出，缺口没有闭成一圈齿轮；中央有独立的 2px 琥珀色点。32px 六臂边界更完整，核心为清楚的 4px 方块。浅底与深底均成立。16px 的斜臂边缘仍有正常抗锯齿，装甲端头的斜切细节不在这个尺寸保留；方向辨识是这个版本的目标。

原稿在 16px 的细颈、外扩斜切会挤在少量像素里。主版在这个尺寸仍显得较短、较团，因此交付强制保留光学版，未把“1024 矢量可缩放”当作小尺寸验证通过。

## 10. 重建与后续

本仓库把交付源复制到 `apps/desktop/assets/brand/`，继续使用现有
`scripts/build-icons.mjs` 生成应用图标、ICNS、托盘和 favicon。在项目根目录运行：

```sh
pnpm --dir apps/desktop exec node scripts/build-icons.mjs
```

SVG 与 1024 源图保持定稿包原样；运行时 PNG 和 ICNS 由现有 macOS 图标流程生成。
原始定稿包的几何构建、预览页和字体轮廓记录仍保留在交付包中，不复制成第二套
运行时生成逻辑。

本次环境中的 Chrome 以退出码 134 结束，未产生页面截图；所有 PNG 均使用 Sharp。预览页已检查 SVG/XML、唯一 ID、内嵌图像、下载内容一致性与主题切换脚本；未将这些检查当作浏览器布局截图验证。

建议下一步：

- 产品内已接入深浅主题资源切换；后续新增入口仍应复用 `BrandMark`，favicon 保持光学版。
- 如需加载动效，沿六条臂顺时针以 60° 节奏依次点亮；核心固定，不持续旋转整枚标识，并支持减少动态效果的设置。
- 发布资产统一从本包的 1024 源文件重新生成，不手工改写小尺寸 PNG。
- 做真实屏幕、深色浏览器标签及小尺寸印刷打样，复核实际背景下的视觉效果。
