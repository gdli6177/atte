# Atte 展示文案

本轮使用的名称为 `Atte`，定位同时保留中文「注意力中心」和英文
`The attention layer`。两者是同一层次的产品定位，不把英文当作临时副标题。
内部标识与旧版迁移见[升级说明](../upgrade-atte.md)。

| 位置 | 文案 |
| --- | --- |
| 窗口、菜单、安装包 | Atte |
| 关于、首启、仓库首页 | 注意力中心 · The attention layer |
| 功能解释 | 人只做拍板，Agent 并行推进。管家把决定、验收和需要介入的事项带到你面前。 |
| 官网描述候选 | Atte 是注意力中心（The attention layer）：一个工作区，一位全局管家，多个项目与 Agent 并行；需要你拍板时再来找你。 |
| 商店描述候选 | Atte · 注意力中心 · The attention layer。集中查看需要决定、验收、到期跟进和现场介入的事项，让管家协调并行 Agent。 |

本仓库没有独立官网或商店发布入口。上表仅供审核使用，未替董事长决定外部发布或执行发布。
名字由来只保留在[内部记录](naming-origin.md)，不进入关于页、README 或对外物料。
