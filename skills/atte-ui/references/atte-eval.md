# Atte UI eval

| 场景 | 必须成立 |
| --- | --- |
| 修改主题 | 改 `tokens.css` 语义映射，首页、详情、设置共用；不在组件增加色值。 |
| 简化界面 | 用留白、字阶、边界表达层级；不恢复轨道、光点、网格、光晕与卡片抬升。 |
| 验收追加要求 | 使用「给管家发消息」，发送 `goal.message`；保留 `review` 与交付，不能由按钮提交 `goal.rework`。 |
| 验收通过 | 保留独立主按钮，继续执行明确验收及 attention 身份校验。 |
| 更换品牌图形 | 通过 `BrandMark` 与 `atte-*` 资产挂点；保留原稿；最终图形与配色未经决定不得自行定稿。 |
| 重排设置 | 未选择存储位置也能打开设置；依赖工作区的编辑与管理先提示选择位置；修改表单后明确保存，失败保留输入。 |
| 首启导航 | 未选择存储位置时，注意力、待办池、全部目标和设置分别显示对应页面；设置内可首次选目录，取消选择保留当前页。 |
| Orca 安装状态 | 缺失、已安装待验证、安装需修复与可切换分别展示；安装与兼容状态不混用，重新检测后两处状态一致。 |
| 名称与公开接口 | 展示 Atte · The attention layer；新包名、命令、协议与目录使用 `@atte/*` / `atte` / `atte.*`，旧标识只在迁移读取路径出现。 |
| 减弱动态效果 | 所有页面尊重 `prefers-reduced-motion`；终端光标也不闪烁。 |
