# Skills

- `atte/`：随桌面应用安装的主协议 Skill，负责目标入口、明确状态写回、
  attention receipt、负责人现场与 CLI 边界。
- `atte-ui/`：桌面 UI 开发约束：token、共享原语、空态/设置/注意力面板与视觉验收清单。项目内使用，不随应用安装。
- `ship-*`：**Legacy**，0.2 手工合同流程的遗留技能，不再随应用安装或参与
  当前流程；仅为历史参考保留。当前用法见 `docs/atte.md`。
- `atte-local-pack-author/`：**Legacy**，0.10–0.13 的本地能力包创建器；0.14
  已退役本地能力包，因此不再随应用安装。目录保留为历史参考，不能重新启用
  安装、挂载或脚本执行。

管家与负责人的内置职责由 Core 的静态上下文提供，不需要安装到 Agent 配置目录。
